# 中文写作排版

一个面向中文小说和长文写作的 Obsidian 插件。缩进、行距和纸张效果只改变 Obsidian 内的显示，不会自动改写正文。

> 当前版本：**0.14.3**

## 从这里开始

1. 在一篇 Markdown 笔记中点击左侧书本按钮：关闭 → 写作模式（简洁版）→ 写作模式（专业版）→ 关闭。
2. 进入专业版后，在右侧“写作工坊 → 版式微调”选择模板或调整字体、字号和行距；这些操作只改变显示。
3. 需要整理 Markdown 原文时，使用独立的“一键排版”。有选区时只处理选区；没有选区时自动处理整篇笔记，可用 `Ctrl+Z` 撤销。

### 版式选择

“版式模板”现在明确区分两种基础方案：

- **跟随 Obsidian**：直接继承当前 Obsidian 主题与外观设置中的编辑器字体、字号、正常行距和可读行宽；不添加插件纸张、首行缩进或两端对齐。适合作为原生排版基准。
- **推荐写作版式**：插件提供的中文长文写作搭配，与 Obsidian 原生默认分开命名。

写作工坊会显示“Obsidian 当前：字号 · 行距”。选择“跟随 Obsidian”后再微调任一版式项目，插件会保留当时的 Obsidian 参数作为自定义起点。单篇独立版式和 `cssclasses` 自动规则同样可以使用“跟随 Obsidian”。

## 功能

- 按笔记开启或关闭写作模式
- 自动筛查 Windows 已安装字体，并可分别设置正文、标题、引用、粗体和斜体字体
- 首行缩进、字号、行距、段距和正文宽度
- 跟随 Obsidian、暖色、米白、复古、浅粉、青绿、雾蓝和深色纸张主题
- 可从当前 Obsidian 库选择图片作为自定义纸张背景
- 阅读视图与实时编辑视图同时生效
- 半角标点、重复标点、未配对引号和手工段首空格提示
- 状态栏显示正文字符数与提示数量
- 右侧写作面板实时调节排版参数
- 可将当前版式保存为自定义模板，并随时应用、覆盖更新或删除
- 可为单篇笔记启用独立版式和模板，不影响其他文档
- 可按不同 `cssclasses` 自动套用不同版式模板，并设置匹配优先级
- 右侧写作工坊的重点色可跟随 Obsidian 主题或使用自定义颜色
- 在面板中查看问题所在行，并点击跳转到原文
- 打字机模式可将输入行固定在编辑区 30%～70% 的自选位置
- 可用柔和背景高亮光标所在的当前行
- 专注模式临时隐藏侧栏、标签栏和状态栏，可按 Esc 退出
- 将当前笔记或当前文件夹整稿导出为 TXT、Word 或分页 PNG
- 导出时可一键移除或保留 Markdown 语法
- 一键打开系统中的“写作导出”文件夹
- 简洁版与专业版写作界面一键切换
- 19 条可组合的一键排版规则与可保存的自定义方案
- 无选区时自动整理整篇笔记，有选区时只处理选区
- 回车换段后，空白输入行自动与正文首行缩进位置对齐
- 桌面端和移动端均可加载

## 安装

从本仓库的 [Releases](../../releases) 下载 `main.js`、`manifest.json` 和 `styles.css`，放进你的 Obsidian 库目录：

```text
<你的 Obsidian 库>/.obsidian/plugins/chinese-writing-layout/
├─ main.js
├─ manifest.json
└─ styles.css
```

然后进入“设置 → 第三方插件”，启用“中文写作排版”。

## 使用

打开一篇 Markdown 笔记，左侧书本按钮会按下面的顺序循环：

1. 写作模式关闭 → 开启写作模式并使用简洁版。
2. 简洁版 → 保持写作模式开启并打开专业版。
3. 专业版 → 关闭写作模式并回到简洁版。

如果只想直接开启或关闭写作模式，也可以运行命令：

```text
中文写作排版：切换当前笔记的写作模式
```

插件会显式添加标准属性：

```yaml
---
cssclasses:
  - chinese-novel
---
```

再次执行命令即可移除。此操作只修改笔记属性，不修改正文。

所有默认值都可以在插件设置中调整。另一个命令“切换小说纸张主题”可以快速轮换纸张效果。

## 简洁版与专业版

- 简洁版：只保留左侧书本按钮，不打开右侧写作工坊。
- 专业版：打开完整的右侧写作工坊，提供排版、校对、沉浸写作和导出功能。

左侧书本按钮负责“关闭 → 简洁版 → 专业版 → 关闭”的循环切换。也可以运行“切换简洁版与专业版”命令，或在插件设置中直接选择界面模式。

## 写作排版面板

点击左侧书本按钮进入专业版，或运行命令：

```text
中文写作排版：打开写作排版面板
```

面板顶部的“写作模式”只负责为当前笔记开启或关闭写作显示，不会整理正文。开启后，通过紧随其后的“版式微调”调整字号、行距、段距、首行缩进、正文宽度、纸张主题和两端对齐；这些设置只改变显示，不会改写 Markdown。

“版式微调”的字体区域采用接近 Obsidian 外观设置的选择方式：侧栏直接显示“正文”和“标题”两个常用入口；“更多字体设置”中分别提供引用（`>`）、粗体（`**文字**`）和斜体（`*文字*`）字体。每一项都可以维护有序字体列表，插件按从上到下的顺序寻找当前设备可用字体；支持添加、移除、拖动排序、上移和下移，并可设置最后的 `serif`、`sans-serif` 或 `monospace` 后备字体。“Windows 已安装字体”区域只列出系统实际检测到的字体；内置宋体、黑体、楷体和仿宋按钮则会应用完整后备组合。安装新的 `.ttf` 或 `.otf` 后重新启动 Obsidian，再点击“重新扫描”即可。插件只读取字体名称，不复制或上传字体文件。

选用“跟随 Obsidian”时，字体区域会以当前 Obsidian 外观设置为准；如需指定多个中文后备字体，请切换到“推荐写作版式”或“当前自定义设置”后编辑对应的字体列表。

当前显示参数可以另存为命名模板。自定义模板支持一键应用、保存修改和删除，并记录五类字体、字号、行距、段距、缩进、正文宽度、纸张背景与两端对齐。开启“此笔记使用独立版式”后，下方设置和所选模板只影响当前笔记；关闭时使用全局版式。打字机模式、校对提示和状态栏开关不会被写入版式模板。

插件设置中的“按 CSS Classes 自动套用版式”可以把不同类名映射到不同模板。例如笔记同时带有 `chinese-novel` 和 `scene-romance` 时，可以自动使用“感情场景”模板：

```yaml
---
cssclasses:
  - chinese-novel
  - scene-romance
---
```

规则从上到下匹配，多项同时命中时采用排在最前面的规则。单篇独立版式优先于自动规则；自动规则生效时继续手动调整版式，会为当前笔记建立独立版式，不会改动其他同类笔记。

“操作界面 → 重点色”默认选择“跟随系统皮肤”，会读取 Obsidian 当前主题的重点色；切换为“自定义”后可以使用颜色选择器。该颜色只影响写作工坊、排版弹窗和导出弹窗的按钮、图标、焦点与选中状态，不会改变写作纸张或正文颜色。

与之不同，独立的“一键排版”会按照选中的空行、空格、缩进和标点规则整理 Markdown 原文；操作前会区分选区或全文，完成后可以立即撤销。修改设置后，右侧面板和正文会保留当前滚动位置。

下方问题列表显示提示类型、行号和上下文。点击一条问题会回到原文并选中对应位置；它只负责定位，不会自动修改正文。

“快捷工具”区域提供：

- 打字机：仅在启用写作模式的编辑笔记中生效，可选择让输入行保持在编辑区 30%、40%、50%、60% 或 70% 的位置。
- 高亮当前行：使用柔和背景标出光标所在行，只改变显示，不会修改正文。
- 专注模式：隐藏左右侧栏、标签栏与状态栏；点击右上角“退出专注”或按 `Esc` 恢复。
- 导出文本：始终排除 YAML 属性，并可选择是否一键移除标题符号、粗体、链接、双链和列表等常见 Markdown 标记；在 Obsidian 库根目录的 `写作导出` 文件夹生成 TXT、DOCX 或分页 PNG。同名文件会自动编号，不会覆盖。
- 导出目录：Windows 桌面端打开系统文件管理器并尝试将窗口切到最前方；移动端在 Obsidian 文件列表中定位。

## 纸张主题

内置主题包括跟随 Obsidian、暖色纸张、柔和米白、复古书页、浅粉纸张、青绿纸张、雾蓝纸张和深色纸张。

选择“自定义图片”后，可以从当前 Obsidian 库中的 PNG、JPG、JPEG、WebP、GIF、BMP 或 SVG 图片选择背景。插件会覆盖一层半透明纸色，避免图片干扰正文阅读；背景只改变显示，不会写入 Markdown 原文。

## 作品导出

点击右侧面板的“导出文本”打开导出窗口。可以导出当前笔记，也可以合并当前文件夹中的全部 Markdown；整稿会按文件名自然排序。

“移除 Markdown 语法”默认开启，适合直接投稿或阅读；关闭后会保留 Markdown 正文原样，适合继续在其他 Markdown 软件中编辑。两种方式都不会导出笔记顶部的 YAML 属性。

- 纯文本（`.txt`）：适合投稿网站、复制和跨软件传递。
- Word 文档（`.docx`）：继承当前字号、行距、段距和首行缩进，识别 Markdown 标题；可选择标题页、页眉和页码。
- 分页图片（`.png`）：继承当前纸张、字号、行距和缩进，长文自动拆成多张图片。

可以选择“导出后打开文件夹”，也可以随时点击“导出目录”或运行“打开写作导出文件夹”命令。所有文件仍保存到 Obsidian 库根目录的 `写作导出/`，同名文件会自动编号。

## 一键排版

在右侧写作面板点击“一键排版”，可以选择“小说整洁”“紧凑正文”“中文标点整理”预设，也可以逐项开关并调整规则顺序：

- 清理行首、行尾以及文首文末空白
- 合并多个连续空行
- 确保正文段落之间有一个空行
- 移除正文中的全部空行
- 合并多个连续空格
- 移除中文字符之间的空格
- 在中文与英文数字之间添加或移除空格
- 移除正文中的所有空格
- 为正文段首加入两个全角空格，模拟真实首行缩进
- 移除手工段首空格
- 常用半角与全角标点互转
- 直引号修复、弯引号与直角引号互转
- 省略号规范化

调整好的开关和执行顺序可以保存为命名方案，例如“投稿版”或“个人阅读版”；保存后可以继续修改或删除。

如果编辑器中有选区，只处理选中文字；如果没有选区，自动处理整篇笔记，不需要先执行全选。YAML 属性区和围栏代码块不会被改动，每次排版都可以使用 `Ctrl+Z` 撤销。

“段首加入 2 个全角空格”会把缩进真实写入 Markdown，适合不支持 CSS 首行缩进的投稿平台；它与只改变 Obsidian 显示效果的“首行缩进”滑杆不同。该规则会将已有段首空白统一为两个全角空格，重复执行不会继续累加，并自动跳过标题、列表、YAML 和代码块。

常用的“移除多余空格”“合并多余空行”和“段落之间增加空行”也可以从编辑器右键菜单或 Obsidian 命令面板直接执行。

## 提示规则

当前版本会提示：

- 紧邻中文的半角 `? ! ; : , .`
- 重复的中文逗号、句号等标点
- 未配对的 `“”`、`‘’`、`《》`
- 使用空格或全角空格制作的段首缩进

提示只使用波浪下划线，不会自动替换。代码块、行内代码和 YAML 属性区会被忽略。

# v1.0.0 发布验收清单

这份清单用于验证 `1.0.0` 私人仓库候选能否正式公开。自动化测试不能替代真实 Obsidian 中的字体、主题、文件选择器和移动端检查。

## 1.2.0 本次增补验收

- [x] 手机阅读预览可从写作排版面板和命令面板打开，不修改原文。
- [x] 手机预览支持三种逻辑屏幕尺寸、纸张样式、字号、连续滚动和双向比例同步。
- [x] 当前文件夹整稿导出识别中文章号与数字前缀，并保持稳定排序。
- [x] 正文宽度可扩展到 120 字宽，保存版式与版式覆盖值均正确限制范围。
- [x] 编辑器命令面板可直接执行一键排版；打字机模式不因仅移动光标或选区而重复居中。

## 自动化门槛

- [x] `npm.cmd test -- --run`：44 个测试文件、247 项测试通过。
- [x] `npm.cmd run build`：TypeScript 检查与生产构建通过。
- [x] `npm.cmd run deploy:local`：三项安装文件已部署并校验哈希。
- [x] 已移除运行时 PowerShell / `child_process` 调用。
- [x] 本地文件相关 Electron / Node 调用均位于桌面平台分支内。
- [x] README、安装指南已按当前功能刷新。

## 升级与数据安全

- [ ] 从 0.15.x 或更早数据升级后，插件能正常启动且设置未丢失。
- [ ] 从 0.18.1 升级后，自定义版式、单篇版式、自动规则和版式历史仍存在。
- [ ] 旧 `chinese-novel` / `activationClass` 笔记仍自动开启写作模式。
- [ ] 旧 CSS Class 版式规则仍只选择版式，不意外开启原本未开启的笔记。
- [ ] 新开关写作模式不会修改正文或主动写入 frontmatter。
- [ ] 文件重命名、移动、删除及重启后，单篇状态与单篇版式没有串到其他笔记。

## 写作模式与版式

- [ ] 书本按钮可完成“关闭 → 简洁版 → 专业版 → 关闭”。
- [ ] 单篇强制开启、强制关闭和恢复跟随规则均正确。
- [ ] 全局默认关闭/开启以及默认模板正确。
- [ ] 文件夹（含子文件夹）、Tag、文件名通配符和 CSS Class 规则正确。
- [ ] 多条自动规则同时命中时，第一条生效。
- [ ] 单篇版式优先于规则模板，规则模板优先于全局默认模板。
- [ ] 编辑视图、实时预览和阅读视图显示一致。
- [ ] 切换多篇笔记和多个 Markdown leaf 时不串版式。
- [ ] 跟随 Obsidian、推荐写作版式、自定义模板与自定义纸张均正确。
- [ ] 浅色、深色主题及不同 Obsidian 重点色下，设置页与写作工坊可读。

## 版式历史与写作辅助

- [ ] 滑杆一次拖动只生成一条历史，数字输入在 Enter / blur 后生成一条历史。
- [ ] 版式撤回、恢复、恢复到历史状态正确，且不影响正文 `Ctrl+Z`。
- [ ] 套用模板、恢复默认等整体操作可以撤回。
- [ ] 打字机模式、高亮当前行、专注模式和 `Esc` 退出正常。
- [ ] 自动打字机与用户手动开关不会互相覆盖持久状态。
- [ ] 中文写作提示、问题定位及两种字数口径正确。
- [ ] 原生查找替换与文件恢复入口能调用 Obsidian 对应功能。

## 字体

- [ ] 跟随 Obsidian 时不残留旧字体覆盖。
- [ ] 宋体、黑体、楷体、仿宋快捷项正确显示当前设备可用性。
- [ ] 正文、标题、引用、粗体和斜体可以分别选择并立即应用。
- [ ] 自定义或推荐版式下，编辑视图与阅读视图的标题字体一致，来回切换不会改变。
- [ ] 导入 `.ttf`、`.otf`、`.woff`、`.woff2` 后立即生效。
- [ ] 重启 Obsidian 后，已导入字体仍能加载。
- [ ] 字体重命名只改变显示名称，不破坏引用。
- [ ] 删除正在使用的字体会提示引用数量，并安全修复所有引用。
- [ ] 字体文件暂时缺失时保留设置、显示提示，不导致插件启动失败。
- [ ] 插件不再扫描整台电脑的系统字体。

- [ ] 在移动端从正文/标题字体选择器导入字体后，该字体立即被选中并应用；修改系统字体不会改变已选用户字体。

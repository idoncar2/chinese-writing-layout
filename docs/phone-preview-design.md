# 手机阅读预览

以用户提供的章节预览截图为界面依据：独立侧栏、手机边框、屏内上下滚动、下方四项控制。服务于作者检查当前文章的手机阅读排版，不修改 Markdown。

## 决策

- 使用右侧独立预览，便于同时编辑和阅读；弹窗会遮挡编辑器，现有实验阅读器的横向分页不符合参考图。
- 复用 Obsidian Markdown 渲染及现有阅读器清理逻辑；不引入新依赖，实验阅读模式保持原状态。
- 提供纸白、暖纸、夜间，16–24px 字号，360×720、390×780、430×860 三种逻辑屏幕尺寸。尺寸代表排版视口，不模拟特定品牌浏览器。
- 屏幕等比缩放以适应侧栏，保持逻辑宽度和换行；正文连续滚动。
- 默认开启双向比例滚动同步。仅同步阅读位置，不改变光标、选区或内容；不同布局的对应段落可能有偏差。
- 当前编辑文章切换时更新预览；编辑内容防抖 350ms 后重绘。异步渲染仅接受最新结果，关闭后清理组件、观察器、事件与定时器。
- 处理单篇日常长文，全部本地处理（Markdown 自带远程图片仍由 Obsidian 处理）；不另建服务，不加入持久化数据结构。控件值在本次面板生命周期内保留。

## 验证

测试尺寸缩放与滚动边界；执行现有回归测试、类型检查和生产构建。部署到本地测试库并核对产物。实际 Obsidian 中检查长文、机型切换、编辑刷新、同步关闭与重新打开。

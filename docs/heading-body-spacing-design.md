# 章节标题与正文空行规则

## 理解与假设

- 一键排版新增“章节标题和正文之间空一行”，默认关闭。
- 章节标题仅指 Markdown ATX 标题（`#` 至 `######`）。
- 仅在标题下一行直接为普通正文时插入一个空行。
- 已有空行、连续标题、列表、引用、代码、分隔线等结构不处理。
- 规则改写 Markdown 原文，沿用一键排版的保存方案和撤销机制。
- 处理保持线性扫描，不读取外部数据，不增加依赖。

## 方案与决策

- 采用现有 Markdown 行分类器判断 `heading → paragraph`，复用一键排版规则管线。
- 不使用标题文字（如“第一章”）进行猜测，避免误改普通段落。
- 与“移除所有正文空行”互斥，避免用户同时选择两个结果相反的规则。
- 不扩展标题前空行或 Setext 标题；出现明确需求后再增加。

## 测试

- 标题直接连接正文时插入一个空行。
- 已有空行不重复插入。
- 标题后为标题、列表、引用、分隔线或代码块时保持不变。
- 规则出现在空行分组，并与全部移除空行互斥。

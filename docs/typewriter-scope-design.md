# 打字机模式作用范围设计

## 已确认行为

- 写作工坊的“打字机”按钮是唯一的手动操作入口。
- 设置项改为“工作台打字机作用于所有文章”，只决定工作台按钮的作用范围。
- 该设置关闭时，工作台按钮只切换当前 Markdown 文章，并按文章保存状态。
- 该设置开启时，工作台按钮维持原有行为：切换一次后对所有文章生效。
- 打字机模式可脱离写作模式使用。
- “开启写作模式时自动启用”以及现有光标定位机制保持不变。

## 假设与约束

- 单篇状态保存在插件数据中，不写入 Markdown 正文或 frontmatter。
- 文件重命名和删除时，单篇状态沿用现有按路径状态的迁移与清理机制。
- 不增加单篇自动规则、跨设备冲突处理或新的全局强制入口。
- 切换文章时只读取一个按路径索引，性能影响可忽略。

## 决策记录

1. 选择“设置决定工作台按钮作用范围”，不保留重复的设置页手动开关。
2. 单篇模式持久保存；全局模式沿用当前实际功能。
3. 允许非写作模式文章使用打字机，避免把滚动体验与排版模式强绑定。
4. 暂不仿照 WonderPen 修改为“开始键盘输入后才重新定位”。

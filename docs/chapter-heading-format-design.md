# Markdown 章节标题统一格式

## 理解摘要

- 一键排版只处理 Markdown `#` 至 `######` 标题开头的章节编号。
- 保留编号后的标题文字，并统一以一个半角空格分隔。
- 支持目标格式：`第12章` / `第2卷`、`第十二章` / `第二卷`、`（十二）`、`12、`。
- 带单位输入保留“章/卷”；无单位输入转为带单位格式时默认使用“章”。
- 只转换现有编号，不自动重排章节顺序。

## 假设与边界

- 支持 1～9999 的正整数。
- 不处理普通正文、YAML、代码块、“序章”“终章”“上卷”等非数字编号。
- 不处理标题中间出现的编号或无法明确解析的内容。
- 所有处理均在本地线性扫描，不增加依赖或外部数据访问。

## 方案比较与决策

- 采用一个“统一章节标题格式”开关和一个目标格式下拉框；格式跟随默认及自定义一键排版方案保存。
- 不采用四个互斥复选框，避免冲突状态；不采用每次执行时弹窗，保持真正的一键排版。
- 复用现有 Markdown 行分类和一键排版撤销机制。
- 使用内部中文数字解析与生成函数，不引入第三方库。

## 测试策略

- 覆盖个位、十位、百位、千位及“章/卷”。
- 覆盖四种来源格式和四种目标格式互转。
- 覆盖副标题保留、空格统一、无副标题、幂等性。
- 验证普通正文、YAML、代码块、模糊标题和超范围编号保持不变。

# Markdown 粗体外部边界修复

## 目标与边界

- 扩展现有“修复 Markdown → 粗体”，不新增设置入口。
- 将 `**重点。**正文` 修复为 `**重点。** 正文`。
- 将 `正文**重点。**正文` 修复为 `正文 **重点。** 正文`。
- 空格只加在完整粗体片段外部，不进入 `**` 内部；行首、行末不增加空白。
- 已有空格或标点边界保持不变；未闭合粗体不猜测。
- YAML、围栏代码、行内代码和链接目标沿用现有保护。

## 方案与决策

- 采用方案 A：扩展现有成对粗体修复函数，并复用当前边界分类逻辑。
- 不扩展斜体和删除线，避免扩大自动改写范围。
- 不移动粗体内部标点，只补粗体片段与相邻正文之间的半角空格。
- 处理保持幂等和线性复杂度，不增加依赖。

## 测试

- 覆盖行首粗体后接正文、句中粗体两侧接正文及多个连续段落。
- 覆盖已有正确空格、标点边界、未闭合标记和受保护 Markdown。
- 验证连续执行结果不变。

- 2026-09-07：用户选择仅扩展现有粗体修复（方案 A）。

# 当前笔记版式来源提示

## 理解总结

- 用户需要辨认当前笔记的版式来自全局默认、自动规则、Obsidian，还是当前笔记独立版式。
- 在工作台“当前笔记”的写作模式说明下新增可点击的版式来源状态行。
- 点击状态行只滚动到“版式微调”的独立版式控制并短暂强调，不改变任何设置。
- “此笔记使用独立版式”开关继续只存在于“版式微调”。
- 调整排版自动形成独立版式、保存与覆盖模板等现有逻辑不变。

## 假设与约束

- 状态从现有实时解析结果生成，不新增持久化字段，不写入 Markdown。
- 切换笔记、模板或规则后随工作台刷新更新。
- 使用原生按钮和焦点语义；高亮支持减少动态效果偏好。
- 不增加第二个独立版式开关或新的版式规则。

## 方案比较与决策

1. 采用“可点击状态行”：信息就近展示，操作仍定位到唯一控制入口。
2. 不复制独立版式开关，避免两个入口造成状态同步和认知负担。
3. 不采用纯文本提示，因为发现问题后仍需手动寻找控制位置。

## 文案规则

- 全局模板：`跟随全局默认｜模板名`
- 自动规则：`自动规则｜模板名`
- 独立版式：`当前笔记独立版式｜模板名`；已微调时优先显示其基础模板。
- Obsidian：`跟随 Obsidian`

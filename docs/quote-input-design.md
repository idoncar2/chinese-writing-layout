# 中文引号输入辅助

已确认行为：输入中文左双引号或左单引号，补右引号并将光标置于中间；光标紧邻本次自动补出的右引号时，Enter 先跳出，之后恢复普通 Enter。无需写作模式，不新增工作台按钮。

实现决策：用 CodeMirror 会话状态跟踪自动生成的左右引号位置，不猜测既有正文中的引号；输入和补齐在一个编辑事务中。删除或覆盖任一符号后清除跟踪，跳出后不再拦截该符号。选区、多光标、代码/YAML/含内联结构的行保守交回原生编辑器。组合输入期间不补全，带修饰键的 Enter 不拦截。用 composition 状态、键盘事件标志和组合结束短窗口避免把选词 Enter 当成跳出。

边界：不是一键排版规则，不扫描修改历史正文；不处理粘贴、其他括号或引号样式。状态不写入笔记或设置。测试采用真实 EditorState 事务，人工仍需在实际 Obsidian 中验证中文输入法及其他自动配对插件的兼容性。未做部署或发布。
